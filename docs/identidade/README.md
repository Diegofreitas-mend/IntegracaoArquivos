# Arvendro Gestão

Identidade criada para uma empresa fictícia de software de gestão comercial,
voltada a pequenos varejistas. O produto reúne vendas, catálogo, estoque e
integração de arquivos no mesmo ambiente de trabalho.

## Nome e marca

**Arvendro** combina referências a armazém e venda em um nome inventado para o
projeto. A apresentação do produto é **Arvendro Gestão**.

O símbolo forma um **A** com dois módulos inclinados e uma barra que lembra uma
prateleira. A construção usa tinta escura para a estrutura e cobre para o
movimento. O logotipo foi finalizado em curvas: os SVGs não dependem de fontes
instaladas para manter sua aparência.

## Arquivos

- `logo-horizontal.svg`: versão principal, com fundo transparente.
- `logo-clara.svg`: versão para fundos escuros.
- `logo-monocromatica.svg`: versão em uma única cor.
- `simbolo.svg`: símbolo isolado, também usado como favicon.
- `logo-horizontal.png`: versão de imagem para documentos e apresentações.

Preserve a proporção da marca e um espaço livre equivalente à metade da altura
do símbolo. Em tamanhos pequenos, use apenas o símbolo.

## Cores

| Cor | Código | Uso |
| --- | --- | --- |
| Tinta | `#22383A` | Marca, títulos e informações principais |
| Cobre | `#B65235` | Ação principal, seleção e assinatura da marca |
| Papel | `#F2F0E9` | Fundo do ambiente de trabalho |
| Marfim | `#FFFEFA` | Formulários e tabelas |
| Verde de status | `#70816B` | Processamento concluído |

## Interface

A organização visual parte de fichas de registro: superfícies claras, divisórias
finas, alinhamento de valores e cantos discretos. A navegação lateral usa o tom
de papel, com a seção ativa marcada em cobre. Títulos usam Bahnschrift quando
disponível, com Segoe UI como alternativa; textos usam a fonte do sistema, e
códigos e cabeçalhos de tabelas usam uma fonte monoespaçada.

O sistema não usa fontes, imagens ou serviços de marca externos durante a execução.
